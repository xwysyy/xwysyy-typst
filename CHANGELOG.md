# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [0.5.0] - 2026-09-29

### Changed

- Requires Typst 0.15.0 and touying 0.8.0
- Themes require five color fields: `sea`, `sky`, `skyll`, `paper`, and `page-fill`
- `end-slide` uses the theme's page fill instead of white

### Removed

- Note output: `xwysyy-note`, `xwysyy-doc`, and `--input mode=note`
- `xwysyy-extras()` and its cetz, fletcher, and theorion integrations
- Theme fields `skyl` and `header-text`, and the top-level `skyl` color; theme dictionaries that still set these fields keep compiling
- The `self` parameter of `new-section-slide`
- The `group` field of layout telemetry objects and auxiliary `extra` values such as `gap_fraction`

### Fixed

- `title-slide(date: ...)` now overrides the deck date

## [0.4.0] - 2026-07-11

### Added

- Semantic layout components for common slide structures: `duo-slide`, `focus-slide`, `grid-slide`, `stack-slide`, `compare-slide`, `stat-slide`, `figure-slide`, and `sidebar-slide`
- Typed layout items, compile-time slot validation, stepwise reveal support, and a linear note-mode fallback
- Layout telemetry v4 and the source-repository `scripts/xwysyy-check` command
- Lazy `xwysyy-extras()` loading for the optional cetz, fletcher, and theorion integrations
- `heading-font` parameter on `xwysyy-pre` and `xwysyy-doc` for the content-page header

### Changed

- Layout components measure their content and allocate space according to the declared item sizing
- Content pages use an open header and a page-number-only footer
- Themes use six required color fields with optional `header-text`
- Bold text, tables, inline code, and code-font fallbacks have updated styling

### Removed

- The fixed-layout `focus-slide` from 0.1.0; the `focus-slide` added in this release is the new layout component
- Theme field `header-fill`
- `footer` parameter on `xwysyy-pre` and `xwysyy-doc`

### Fixed

- Long content-page titles shrink to stay within the header
- Visual regression rendering replaces its output set only after every page compiles
- Inline code no longer sinks below the surrounding baseline
- Arrow replacement no longer turns `<=` and `->` inside code into math arrows

## [0.3.0] - 2026-07-02

### Added

- Universe template metadata and `template/main.typ` for `typst init @preview/xwysyy:0.3.0`
- `thumbnail.png` generated from the template first page
- Direct custom theme dictionaries for `xwysyy-pre(theme: ...)`
- Slide font parameters: `font`, `code-font`, and `lang`
- Language-aware `outline-slide(title: auto)` with `Contents` for English and `目录` for Chinese
- Built-in `forest`, `midnight`, `violet`, and `graphite` themes
- `xwysyy-doc` for one-source deck and A4 note output through `--input mode=note`
- Handout example through `--input handout=true` in `examples/slides-sky.typ`
- Speaker-note example and pdfpc query documentation
- `examples/theme-preview.typ` and `examples/dual-source.typ`
- GitHub Actions visual regression workflow
- Scripts for preview generation, visual rendering, PNG comparison, and theme contrast checks
- Visual regression baselines under `tests/visual-baseline`

### Changed

- Quick start now uses Typst Universe package import and template initialization
- `xwysyy-pre` now passes `code-font` through to `xwysyy-elements`
- README theme previews are generated by `scripts/gen-previews`
- Documentation now treats editing `src/themes.typ` as a maintainer/vendor path

## [0.1.0] - 2026-05-14

### Added

- Seven slide layouts: cover (`title-slide`), outline (`outline-slide`), section transition (`new-section-slide`), content (`xwysyy-slide`), focus (`focus-slide`), full-screen image (`image-slide`), and closing (`end-slide`)
- `outline-slide` collects level-1 `=` headings automatically or takes a list of sections
- `textbox` multi-column equal-height text boxes, built on `components.lazy-layout`
- Built-in `sky` (blue) and `sunset` (warm red) color themes
- `red`, `bred`, `yellow`, and `byellow` color emphasis macros
- Synthetic CJK italics through per-character skew
- `xwysyy-note` note mode for theme-independent A4 academic notes
- Automatic arrow replacement (`->`, `=>`, `<=>`, and more)
- AI theme generator guide (`docs/THEME-GENERATOR.md`)
